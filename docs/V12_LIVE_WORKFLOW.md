# v12 Live Workflow

1. Start with an empty FMS Catalog.
2. Click Create FMS.
3. Fill real FMS identity information.
4. Stage 1 exists initially and can be renamed. WHAT/HOW/WHO/WHEN are editable.
5. Add later stages only when needed. Each added stage starts blank except system form fields.
6. Configure the selected stage form. Add, edit, reorder and delete non-system fields.
7. Existing Google Form URL is optional.
8. Configure responsible person name plus email and/or phone.
9. Approve the form.
10. Click Send now. Email is sent only when SMTP is configured. Phone/WhatsApp requires a messaging webhook/provider.
11. Responsible person opens the approved form, fills required fields, uploads actual evidence and submits.
12. PC reviews the response/evidence and selects DONE, CORRECTION, HOLD or EXCEPTION.
13. Submission itself never completes the stage.
14. Later stages remain locked until the previous stage is completed by the PC.
